# Research formulation and evaluation protocol — proposed, not completed

The protected asset is correct backend execution and availability. Model-routing optimization cannot disable mandatory enforcement or retroactively reverse an HTTP operation. An adversary may vary request syntax, repeat requests, share an IP with benign users and induce load. Dependency outage, stale evidence and poisoned operator feedback are separate failure conditions. Host compromise, a compromised administrator and full volumetric network denial of service are outside the protection demonstrated here.

Let x contain only evidence available before route selection, and A(x) contain available routes. Choose route a from A(x), minimize measured expected detection cost E[c(a,x)], and enforce empirical validation gates for attack recall, benign FPR, queue occupancy and latency. Enforcement remains a deterministic mapping from mandatory rules, calibrated evidence and explicit fallback policy. A useful experimental reward is labeled correctness minus configured FN/FP, latency, compute and queue penalties; verified labels must be distinguished from detector predictions. No formal guarantee is implied by empirical gates.

For future split conformal calibration, use a disjoint calibration population and nonconformity 1-p(y|x). Select the finite-sample higher quantile at ceil((n+1)(1-alpha)), with an explicit all-classes result when the rank exceeds n. Report coverage, class coverage, set size, invocation cost and shift failures. Fit neither thresholds nor policy on the new final evaluation data. Compare against confidence, margin, entropy and tuned simple deferral before adding complexity.

For future bandits, start with LinUCB and a cost-sensitive baseline, use action availability masks and baseline-relative empirical constraints, and run learned policies in simulation/shadow first. Context must not contain outputs of an unexecuted detector. Full-information replay may precompute eligible model outcomes on the same development samples. IPS/DR evaluation requires logged stochastic propensities, overlap and the appropriate assumptions; existing deterministic events do not supply them.

For future reconciliation, retain immutable original decisions, append delayed revisions with model/policy versions, use a short-lived pseudonymous session key and decay/correction rules, and apply mitigation only to future or still-pending operations. Compare no reconciliation, existing forward-only source blocking and bounded session history. Measure subsequent malicious requests, benign disruption, correction and expiry, not a fictional prevented original operation.

H1–H4 remain hypotheses: guarded routing may lower cost at comparable effectiveness; conformal assistance may reduce unnecessary deep calls; delayed reconciliation may improve subsequent containment; endpoint profiles/parser consistency may improve robustness. All remain untested in the proposed form.

Freeze development, calibration and new untouched evaluation populations and group by application/template/session/time when available. Repeat comparable workload/concurrency trials on recorded hardware. Required future comparisons include rules-only, pinned OWASP CRS-only, original fusion/hierarchy, tuned thresholds, always-deep where feasible, conformal deferral, unconstrained/constrained routing and the integrated system. The existing CRS Compose service fronts the gateway and uses a mutable tag, so it is not a measured CRS-only baseline.

Record completed and fully inspected throughput separately, classification and enforcement confusion separately, per-class recall/FPR, macro-F1, recall at fixed FPR, latency p50/p95/p99, queue delay, invocation distribution, CPU/RAM/GPU/VRAM and fallback counts. Use paired/repeated experiment intervals, record cold/warm state and hashes, and never turn dependency failures into benign true negatives. Add all requested ablations only after their implementations exist. Current six-probe diagnostic latencies have no performance-comparison interpretation.

Paper outline: problem and threat model; related work and unresolved novelty gap; preserved gateway architecture; routing/calibration/reconciliation methods; frozen experiment protocol; measured results and ablations; failure behavior; limitations/reproducibility. Results, learning curves, tradeoff plots and containment comparisons remain incomplete. No plots are fabricated from hypothetical performance.
